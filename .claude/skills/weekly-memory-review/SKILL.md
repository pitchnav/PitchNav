# Weekly Memory Review

Use `01_MEMORY/MEMORY_HEALTH_CHECK.md`.

Review:

- Current focus
- Memory inbox
- Canonical facts
- Active decisions
- Product truth
- Technical memory
- Session handoff
- Changelog

Find:

- Stale information
- Contradictions
- Drafts described as facts
- Missing dates or sources
- Always-loaded files that are too long
- Secrets or private data

Make only safe memory-maintenance edits.
Report every change.
