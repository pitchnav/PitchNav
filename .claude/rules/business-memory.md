# Business Memory Rules

- Treat `01_MEMORY/CANONICAL_FACTS.md` as confirmed factual memory.
- Treat `01_MEMORY/ACTIVE_DECISIONS.md` as current approved direction.
- Treat `01_MEMORY/MEMORY_INBOX.md` as unverified.
- Do not promote an inbox item into canonical memory without evidence.
- Date meaningful memory changes.
- Preserve superseded information in history.
- Update `09_SESSIONS/SESSION_HANDOFF.md` after substantial work.
- Keep always-loaded memory concise.
