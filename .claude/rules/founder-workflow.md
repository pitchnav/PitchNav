# Founder Workflow Rules

Luke prefers simple, exact, sequential instructions.

For technical tasks:

1. Explain the current situation simply.
2. State the single step being performed.
3. List exact files or commands.
4. Make a contained change.
5. Test it.
6. Give one manual verification action.
7. Pause before the next major step.

Do not assume Luke knows repository paths, terminal navigation, package managers, or infrastructure terminology.
