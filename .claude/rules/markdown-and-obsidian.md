# Markdown and Obsidian Rules

- Preserve YAML frontmatter.
- Preserve Obsidian wikilinks.
- Use descriptive headings.
- Avoid renaming notes without updating links.
- Do not rewrite a whole note when a small edit is enough.
- Keep canonical memory concise.
- Put detailed procedures in skills or topic notes.
