# Advisor photos

Drop square-ish photos here, then reference them from `src/lib/advisors.ts`:

    { name: "Jack O'Connor", affiliation: 'Notre Dame', previously: 'UCLA',
      photo: '/advisors/jack-oconnor.jpg' }

Rendered at 56x56 in a circle, so a clear phone photo is plenty — no studio
shoot needed. Face roughly centered, shoulders-up, not backlit.

Use photos the advisor owns and has sent you. Official team headshots are
generally the athletics department's property, not the athlete's, and media
outlet posts belong to the outlet — neither is cleared for use on a page that
sells memberships just because the athlete agreed to be listed.

Until a photo exists for someone, the strip renders their initial. That is a
deliberate fallback, not a missing asset.
