# Brand Memory

## Identity

Pitch Nav should feel like a premium sports-technology company, not a generic AI app.

## Visual direction

- Dark navy
- Electric or performance blue
- White
- Clean spacing
- Strong typography
- Realistic pitching imagery
- Scientific overlays
- Smooth motion
- Mobile-first execution

## Avoid

- Cartoon anatomy
- Floating athletes or unrealistic floors
- Cheap neon overload
- Generic robot imagery
- Overly busy screens
- Fake-looking AI faces or mechanics
- Long technical paragraphs for athletes

## Existing language directions

- Navigate Your Next Level
- Analyze. Adjust. Advance.
- Understand Your Delivery. Build Better Velocity.

The last phrase should be treated as marketing direction and not as a guaranteed result.

## Tone

- Confident
- Clear
- Competitive
- Precise
- Honest
- Never medically overconfident
