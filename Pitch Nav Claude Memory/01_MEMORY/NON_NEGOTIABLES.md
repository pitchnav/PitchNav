# Non-Negotiables

## Business memory

- Do not turn an unconfirmed idea into a canonical fact.
- Do not silently delete or rewrite decision history.
- Date important changes.
- Keep the current-state notes current.
- Mark assumptions and unknowns clearly.

## Engineering

- Never expose or commit secrets.
- Never use production for experimentation.
- Never deploy autonomously.
- Never make destructive database changes without review and rollback.
- Enforce authorization on the server.
- Use least-privilege tools.
- Log agent runs and consequential tool calls.
- Require approval for external or irreversible actions.

## Product truth

- Never claim a feature exists unless verified.
- Never invent analytics or user feedback.
- Never invent accuracy, velocity, injury, or conversion results.
- Show measurement confidence.
- Reject unusable video rather than creating confident nonsense.

## Athlete safety

- No medical diagnosis.
- No declaration that an athlete is safe to throw.
- No guarantee of injury prevention.
- No guaranteed velocity gain.
- No instruction to throw through pain.
- No unsupported medical, drug, peptide, or supplement recommendation.
