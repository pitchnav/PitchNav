# Agent Permissions

## Permission ladder

1. Read approved data
2. Create internal finding
3. Create draft
4. Request approval
5. Execute a narrow approved action
6. Administrator

No agent receives administrator access by default.

## Approval required

- Publish content
- Send email or direct messages
- Spend money
- Change pricing
- Issue refunds
- Change accounts
- Deploy code
- Modify production data
- Share athlete data
- Make meaningful workload changes

## Separation

The agent proposing an action cannot approve its own action.
