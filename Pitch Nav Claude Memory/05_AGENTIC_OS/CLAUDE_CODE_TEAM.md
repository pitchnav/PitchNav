# Claude Code Team

This vault includes project subagents in `.claude/agents/`.

## Memory Curator

Maintains canonical memory without turning assumptions into facts.

## Founder Chief of Staff

Creates concise founder briefs and prioritizes verified work.

## Product Manager

Converts evidence into small product requirements.

## Marketing Strategist

Creates on-brand, claim-safe marketing drafts.

## Research Reviewer

Reviews evidence and separates findings from inference.

## Security Reviewer

Reviews code and agent workflows for authorization, secrets, and excessive permissions.

## Engineering Planner

Inspects the current codebase and creates safe implementation plans before code changes.

## Use

Ask naturally:

```text
Use the memory-curator agent to review the Memory Inbox.
```

or select the agent using Claude Code’s agent interface.
