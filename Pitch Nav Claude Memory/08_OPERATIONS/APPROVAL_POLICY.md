# Approval Policy

Explicit founder approval is required before:

- Publishing
- Sending email or DMs
- Spending
- Pricing changes
- Discounts
- Refunds
- Account changes
- Production deployment
- Destructive migration
- Athlete data sharing
- Consequential workload or training-plan change

## Approval record

- Action
- Exact payload
- Agent
- Evidence
- Risk
- Approver
- Time
- Result
