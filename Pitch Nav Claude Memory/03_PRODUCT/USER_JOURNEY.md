# User Journey

## 1. Discover

The athlete or coach sees educational content, a referral, or product proof.

## 2. Understand

The landing page explains:

- What Pitch Nav does
- Recording requirements
- Example output
- Pricing
- Limits and safety

## 3. Record

The product guides the user into a supported camera setup.

## 4. Validate

The product checks whether the video is usable before presenting analysis.

## 5. Analyze

The pipeline produces only supported measurements.

## 6. Explain

The report shows:

1. Summary
2. Highest-priority finding
3. Supporting measurement
4. Confidence
5. Practical next step

## 7. Improve

The athlete follows an approved development focus.

## 8. Reassess

The product tracks comparable sessions over time.
