# Product Metrics

## Acquisition

- Qualified visitors
- Account creation rate

## Activation

- Onboarding completion
- Usable upload rate
- Analysis completion
- Time to first useful result

## Conversion

- Pricing-view rate
- Checkout start
- Paid conversion

## Retention

- Second valid analysis
- Week-one return
- Coach usage
- Subscription retention

## Reliability

- Video rejection rate
- Processing failure rate
- Unsupported metric rate
- Average processing time
- Support contact rate

## Rule

Every metric must have an exact event definition and query before an agent uses it.
